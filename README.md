# LinkBio

Página pessoal de links, projetos e serviços de Thales Alves.

Site estático em HTML, CSS e JavaScript, sem banco de dados. Para visualizar localmente, sirva a pasta raiz com `python3 -m http.server 8000`.

A página publicada é hospedada no ChatGPT Sites; alterações neste repositório não são implantadas automaticamente nela.
