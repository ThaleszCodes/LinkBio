# LinkBio

Página pessoal de links, projetos e serviços de Thales Alves.

Site estático em HTML, CSS e JavaScript, sem banco de dados. Para visualizar localmente, sirva a pasta raiz com um servidor HTTP estático, por exemplo `python3 -m http.server 8000`.

A página publicada atualmente é hospedada no ChatGPT Sites; alterações neste repositório não são implantadas automaticamente nela.
